## 3. 方法论与已知偏差

1. **合成自检索高估**：查询由文档自身标题/首块内容构造，属「按文档自己找自己」，其结果上界高于真实用户问法；真实读值以 §2.3 精选问句为准。
2. **社区（community）标题特异性低**：Stack Overflow 问答标题为句子，「标题自检索」难精确命中同一文档，属预期偏差，不反映检索故障。
3. **阈值/boost 来源**：读取 application.yml 实际配置，非代码默认值。
4. **相关性粒度**：合成 = doc 级单相关；精选 = 标题级（标题 → 该标题全部 doc_id 视为相关）。
5. **可复现**：抽样固定 seed=42，语料为活跃 1445 篇；结果明细见 data/baseline/result-*.json。
