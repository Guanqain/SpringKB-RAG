# 脱敏扫描测试样本（全部为虚构数据）

> **用途**：验证「团队可见」文档发布前的脱敏拦截是否生效。
> **声明**：本文所有密钥、令牌、证件号、卡号、手机号、连接串均为**虚构示例**，不具备任何真实效力。
> **注意**：本文件不要放进 `data/raw/`（那里会被导入链路读取），仅作人工测试素材。

## 1. 测试步骤

| # | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 登录后进入 `/editor`，上传本文件（`.md`）或以**团队可见**发布 | 返回业务码 **422**，`data.findings` 列出命中的规则类型 / 命中数量 / 打码样例；文档**不落库** |
| 2 | 同一内容改为**私有**可见性发布 | 成功发布（私有文档不扫描、不审核），自己可在「我的文档」看到 |
| 3 | 进 `/admin/scan-rules` 查看「拦截留痕」 | 出现 1 条记录：动作=发布文档/上传文件、规则类型、命中数量、操作者、时间；**不含正文与明文** |
| 4 | 在 `/admin/scan-rules` 关闭任意一条规则（如「手机号」）后重新发布 | 该规则对应的命中项消失；若已无其他命中则发布成功（进入待审核） |
| 5 | 新增自定义规则（见第 4 节「工号」）后发布含工号的文本 | 命中自定义规则并被拦截 |
| 6 | 管理员在 `/admin/moderation` 审核第 4 步的文档 | 通过 / 驳回后，该作者顶栏铃铛出现未读通知 |

## 3. 预期命中汇总

| 规则 code | 预期命中数 | 说明 |
| --- | --- | --- |
| private_key | 1 | 只认 `BEGIN ... PRIVATE KEY` 头，`END` 行不计数 |
| cloud_key | 3 | AKIA / ghp_ / sk- 各 1 |
| jwt | 1 | 三段均需 ≥8 字符 |
| credential | 3 | `password=`、`api_key:`、`openai_api_key =` 各 1（字段名命中即算，规则重叠属正常） |
| connection_string | 2 | jdbc 与 mongodb+srv 各 1 |
| id_card | 1 | 仅按格式匹配，不校验校验位 |
| bank_card | 1 | 空格分隔的 4 组写法 |
| phone | 2 | 中国大陆 13~19 段 |

> 以上数字已用内置正则对本文实测得出，可直接作为验收基线；若某条规则被管理员关闭，对应行应从响应中消失——这是验证「规则可配置」的关键对照。

## 4. 自定义规则测试（工号 / 内网 IP）

在 `/admin/scan-rules` 新增规则后，用下列样本验证：

- 规则名称：`工号`，测试样本 `工号：EMP-2026-0001`

```
\bEMP-\d{4}-\d{4}\b
```

- 规则名称：`内网 IP`，测试样本 `10.20.3.14`

```
\b(?:10|172\.(?:1[6-9]|2\d|3[01])|192\.168)\.\d{1,3}\.\d{1,3}\.\d{1,3}\b
```

- 规则名称：`内部域名`，测试样本 `wiki.corp.example.com`

```
\b[a-z0-9-]+\.corp\.example\.com\b
```

要点：

- 新增这三条规则后再发布本文，会在原有 8 类之外**额外命中**：工号 1 处、内网 IP 2 处（`10.20.3.14` 与连接串里的 `10.0.0.12`）、内部域名 1 处。
- 自定义规则可改正则、可删除；内置规则**不可删除**，只能关闭。
- 写入非法正则会被拒绝（提示「正则表达式无效」），不会把整条扫描链路弄坏。
- 新增后立即生效，无需重启。

## 5. 已知盲区（本次测试可复现）

1. **`sk-proj-` 型密钥不命中**：内置 `cloud_key` 要求 `sk-` 后连续 ≥20 位字母数字，而 `sk-proj-AbC...` 里的连字符会截断匹配。若团队使用新版 OpenAI 密钥，建议加自定义规则 `sk-proj-[A-Za-z0-9_-]{20,}`。
2. **`credential` 只看字段名**：`password = ***` 这种打码后的值仍会被命中（误报），因为规则匹配的是「字段名 + 6 位以上取值」。
3. **身份证/银行卡不做校验位校验**：随机编造的号码也会被拦截（宁误报不漏报）。
4. **手机号只覆盖中国大陆 13~19 段**：海外号码、带 `+86` 前缀且用空格分隔的写法不会命中。
5. **扫描范围是「标题 + 正文」**：图片、附件（后续若支持）不在扫描范围内。
