在 Spring Boot 中如何配置 CDS？
2026-10-20 · 耗时 2.3s

在 Spring Boot 4.2 中，CDS（Class Data Sharing）可以通过以下方式启用 [1]：

  1. 在 application.properties 中设置 spring.boot.cds=true
  2. 执行 java -XX:+AutoCreateSharedArchive 生成共享归档
  3. 下次启动时 JVM 会自动加载共享归档文件

CDS 能显著缩短 Spring Boot 应用的启动时间，特别是在容器环境中 [1]。

Actuator · 监控端点

4.2-SNAPSHOT 官方来源 收录于 2026-09 已验证

什么是 Actuator

Spring Boot Actuator 提供了一组生产就绪的特性，帮助你监控和管理应用。通过 HTTP 端点或 JMX，你可以获取应用的健康状况、指标、配置属性、环境变量等运行时信息。

启用端点

引入 spring-boot-starter-actuator 依赖后，默认只暴露 /actuator/health。可以通过配置开放更多端点：

management:
  endpoints:
    web:
      exposure:
        include: health,info,metrics,env
  endpoint:
    health:
      show-details: when-authorized

常用端点一览

  • /actuator/health — 应用健康状态，支持自定义 HealthIndicator
  • /actuator/metrics — JVM、HTTP、数据源等指标体系
  • /actuator/env — 当前生效的全部配置属性
  • /actuator/beans — 容器中所有 Bean 及其依赖关系

生产环境安全建议

Actuator 端点会暴露大量内部信息，生产环境务必结合 Spring Security 做访问控制，或将其挂在独立管理端口（management.server.port）并仅对内网开放。

1. 定位慢 SQL

spring.datasource.url=jdbc:mysql://db:3306/app
logging.level.org.hibernate.SQL=DEBUG

2. 常见原因

  • 缺少索引（全表扫描）
  • N+1 查询问题
  • 大分页深度翻页

3. 处置流程

先用 EXPLAIN 看执行计划，再决定是否加索引或改写 SQL。
